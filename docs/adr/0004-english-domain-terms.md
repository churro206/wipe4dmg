# ADR 0004: Code und Data Files verwenden die englischen Begriffe aus dem Glossary

Status: angenommen · Datum: 2026-10-18

## Kontext

Destiny 2 und die Community verwenden englische Fachbegriffe. Gemischte Begriffe im Code erschweren die Suche und die Zusammenarbeit mit Claude.

## Entscheidung

- Bezeichner, Data Files und Kommentare im Code sind englisch.
- Jeder Fachbegriff entspricht genau einem Eintrag im Glossary des Anforderungsdokuments.
- Dokumentation und Erklärungen für das Team sind deutsch. Fachbegriffe bleiben auch dort englisch.

## Folgen

- Neue Begriffe kommen zuerst ins Glossary, danach in den Code.
